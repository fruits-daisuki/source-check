# 対象同定と完全一致

1. 検索前に、ユーザー指定属性と、答えを変え得るカテゴリ固有属性を照合キーとして固定する。未指定属性を推測で埋めない。
   - 製品・機器・部品: メーカー、製品名、型式・型番・SKU・部品番号、容量・等級、世代、地域、状態、販売者・契約、税込・送料、確認時点。
   - サービス・ソフトウェア: 提供主体、製品、Chat/Work/Codex/API等の利用面、Web/デスクトップ/モバイル、モデル名とモード、契約プラン、個人/組織、地域、段階提供・旧契約等の条件、対象時点。プラン名とモデル名、メッセージ枠とクレジット枠、利用権と残量表示を別属性として扱う。
   - 医薬品: 有効成分（塩・エステル・配合成分を含む）、販売名・一般名、剤形（即放・徐放などを含む）、規格・濃度、投与経路、用法・用量、包装単位。効能・安全性に関係する時は適応、対象集団、年齢も含め、製剤規格と服用量を混同しない。
2. 数値は、照合キーと数値が同じ表の行、製品カード、選択済み構成、見積状態、公的文書の同じ節で結び付く場合だけ採用する。大きく表示された初期価格、周辺見出し、スニペット、`from`価格、範囲下限、会員・クーポン・下取り・定期価格だけでは一致としない。
3. 選択式ページでは、選択中の容量・規格・構成と表示価格に対応するSKU・型番または選択状態を確認する。選択、地域、通貨、再読込後は以前の数字を無効にする。URL、画面選択、タイトル、構造化データが食い違うか、状態を取得できない場合は「未確認」とする。
4. 照合キーが1つでも異なる候補は不一致として除外する。表記や単位を正規化する時は基準量と次元が同じで数学的に等価か確認し、原文値も残す。別ページの仕様と価格は、同じ安定識別子が両方に明記される時だけ結合する。
5. 候補を「完全一致」「関連するが不一致」「不明」に分け、数値・直接根拠には完全一致だけを使う。価格や結論を変える選択肢がある時は採用条件を明示する。一致が見つからないだけなら「確認した範囲では見つからない」、取得不能なら「未確認」とする。正本や完全な一覧で不存在を確認できた時だけ範囲付きの「該当なし」とする。近似品は必要な場合に差分付きの参考情報として別記し、指定対象の価格・数値の代わりに使わない。
6. 送信前に「要求属性 → 出典属性 → 数値」の対応を見直し、別候補の数字が混入していないことを確認する。
