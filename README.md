# source-check — AIの調査で出典・対象・条件を確かめる

「出典はあるけれど、別のプランの説明だった」「表示価格に条件付きの割引が混ざっていた」。そんな取り違えを減らすための、日本語のAgent Skillです。

一次資料の本文を読み、質問の対象・時点・条件と照合し、確認できなかったことを残す手順をまとめています。検索サービスや検証済みデータベースを提供するものではありません。

## できること

- 製品の仕様・価格、サービスの利用条件、法令、統計などを、一次資料の本文と照合する。
- 型番、容量、プラン、地域、適用日など、答えが変わる条件を区別する。
- 商品ページの価格、割引条件、税・送料を含む支払額、ポイント還元を分ける。
- 資料間の矛盾や取得できなかった範囲を示し、「見つからない」を「存在しない」に置き換えない。
- 主張の裏取りでは、支持する資料だけでなく、不支持・限界を示す資料も確認する。

提供された文章だけの要約・翻訳、単純な計算、ローカルファイルだけで終わる確認には、外部検索を追加しません。

## 必要な環境

- `SKILL.md`を読み込めるAIエージェント。
- 許可された外部検索・ページ本文の取得手段。
- `references/`のMarkdownを読めるファイル参照機能。

他の個人スキル、追加の実行スクリプト、特定のAPIキーは不要です。利用するAIや検索サービスの契約・利用条件は、それぞれの環境に従います。外部取得ができない場合は、外部未検証であることを示します。

## 導入と使い方

1. このリポジトリをクローンするか、GitHubの **Code → Download ZIP** から取得します。
2. 利用するエージェントのスキル保存先に、`source-check`という名前のフォルダーとして配置します。`SKILL.md`と`references/`の位置関係を保ってください。ZIPの展開先が`source-check-main`になっている場合は、配置するフォルダー名を`source-check`にします。
3. エージェント側で読み込まれたことを確認し、次のように依頼します。保存先・再読込み・呼び出し方は利用製品の案内に従ってください。

```text
$source-check を使って、指定したサービスの現在の利用条件を公式情報で確認して。
プラン・地域・適用日を区別し、結論の近くに出典と未確認の範囲を示して。
```

商品価格を調べる場合は、次のように対象を指定できます。

```text
$source-check で、Laptop Zの512GB・日本向け新品1台の購入価格を調べて。
割引条件と送料を含む支払額を確認し、ポイント還元は別に示して。
カート操作や購入はしないで。
```

`Laptop Z`は使い方を示す架空の製品名です。実際の依頼では調べたい製品名・型番に置き換えてください。

形式は[Agent Skills仕様](https://agentskills.io/specification)を参照しています。`agents/openai.yaml`は対応環境向けの表示情報です。各製品での導入・自動選択・検索動作を横断検証したものではありません。

## 確認結果のイメージ

以下は手順を説明する架空の例です。実際の実行結果や精度改善の測定ではありません。

| 調べたいこと | 得られた資料 | 回答で区別すること |
|---|---|---|
| 512GB版の価格 | 初期表示には256GB版の価格だけがある | 256GBの金額を代用せず、512GBの選択状態を確認する。取得できなければ未確認とする |
| 割引後に支払う金額 | 税込10万円、10%引きと8,000円引きは併用不可、送料1,000円 | 適用資格が同じなら10%引き側の計算額は91,000円。両方の割引を足さず、計算額とカートで確認した金額を区別する |
| モデルの残り利用回数 | ヘルプには対象者がクレジットを購入できるとだけ書かれている | 購入できることを、残り回数が表示される根拠にしない |

実際の調査では、結論・重要な条件・出典・未確認範囲を、質問に必要な長さで示します。

## 検証の範囲と限界

公開版では、ファイル構造、YAML、相対リンク、他の個人スキルへの必須依存がないことを静的に確認しています。評価用ケースは期待動作を記したもので、自動テストの実行結果ではありません。

公開版の独立した実行比較、各AI製品での自動選択、正答率・処理時間の改善は未検証です。AIの誤答や確認漏れをなくすこと、回答の正確性、特定の用途への適合性は保証しません。

本スキルは文章による手順です。通信の遮断、権限の制限、操作の承認を強制する機能は含みません。実際のアクセス制御は利用環境で設定してください。調査の依頼を、購入・投稿・カート変更・機密情報の外部送信の許可として扱わないよう指示しています。
